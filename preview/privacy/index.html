Maths with Animals

Privacy policy

Last updated 31 October 2026

Maths with Animals collects nothing. It has no accounts, ads, analytics or purchases, and it sends nothing anywhere. Progress stays on the device, and nothing is shared with anyone.

What the game collects

Nothing. The game never asks for an email address, age or location. It uses no cookies or trackers, and it has no chat and no way to reach other players. We can't tell who plays, how they play or how often.

Where progress is kept

Progress stays on the device, in the browser's storage for this game. That includes any names typed into the game, such as a name for a friend on the island. None of it leaves the device.

Backup files

The game can write a backup of its progress to a file. That file goes only where you save it. The game never sends it anywhere, and it reads a backup only when you choose to restore one.

Going online

The game runs offline after the first load. It goes online only to download its own files: on the first load, and for any update when the device is online. It sends nothing of its own in those requests.

Those files are stored on GitHub Pages. As with any website, GitHub's servers see a device's internet address when the device asks for a file. GitHub's own privacy statement covers that, and we never see it. The game runs inside a browser, normally Chrome, and the browser's own privacy terms cover the browser itself.

Sharing

Nothing is shared with anyone. We hold no information about you or your child, so there is nothing to share.

Children

This game is made for children, and it is built so that it collects no personal information from them at all.

Keeping data safe, and deleting it

Nothing reaches us, so we have nothing to store, protect or delete. Progress on the device stays there until you remove it. To delete it, clear the site data for bluesybob.github.io in your browser's settings. Removing the app may leave that data in place, so clear it there as well.

Changes to this policy

If this policy changes, the new version will appear on this page with a new date.

Questions

Please ask through the developer contact on the game's Google Play page.
